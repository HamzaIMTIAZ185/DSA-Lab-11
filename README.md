## 🛠️ Tasks & Implementation Details

### **Task 1: Manual Binary Tree & Traversals**
* **Objective:** Manually construct a simple Binary Tree (non-BST) with at least 5 integer nodes.
* **Traversals Implemented (Recursive):**
  * **In-order:** Left → Root → Right
  * **Pre-order:** Root → Left → Right
  * **Post-order:** Left → Right → Root

### **Task 2: Binary Search Tree (BST) Insertion & Display**
* **Objective:** Implement a dynamic BST utilizing the BST property (left child < parent < right child).
* **Key Feature:** Uses recursive insertion and displays elements in ascending order via In-order traversal.

### **Task 3: Recursive BST Search**
* **Objective:** Extend the BST implementation with a recursive search function.
* **Key Feature:** Prompts the user for a value and returns whether it exists within the BST.

### **Task 4: Find Minimum and Maximum in BST**
* **Objective:** Write recursive functions to locate the structural extremes of the BST.
* **Key Feature:** Reaches the leftmost node for the minimum value and the rightmost node for the maximum value.
